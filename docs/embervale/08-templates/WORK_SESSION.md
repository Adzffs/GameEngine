# Work session and handoff template

- Date and contributor:
- Goal, task ID and branch:
- Starting source commit/content version:
- Files inspected and changed:
- Decisions made and supporting evidence:
- Commands/checks run and actual results:
- Demonstrated outcome:
- Remaining failures, uncertainties and blockers:
- Compatibility/rollback considerations:
- Documentation and status updates:
- Next bounded action:

Keep this record concise. A useful handoff tells the next person what is true now and how to continue; it does not need a chronological transcript of every keystroke.
