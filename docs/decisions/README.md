# Open design decisions

Use one decision record per choice that affects multiple features. Resolve these before large content production:

- What world premise, tone and central identity distinguish the game?
- What player-facing combat rhythm should the tick-based engine support?
- Are pets cosmetic companions, utility partners, combat partners or a mix? How are they obtained?
- How are recipes taught, shown or discovered?
- Which skills define the long-term progression and unlocks?
- Is cooperative online play part of the initial player promise?
- How should rare boss rewards interact with trading and essential progression?

Use [the decision record template](../templates/decision-record.md). When decided, update the Game Design Document and affected system briefs in the same PR.
