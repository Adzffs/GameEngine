# Contributing to Embervale / GameEngine

Start with the [contribution guide](docs/embervale/06-development/CONTRIBUTING.md), then read [Getting started](docs/embervale/06-development/GETTING_STARTED.md), the [current source inventory](docs/embervale/01-current-state/IMPLEMENTED_SYSTEMS.md) and the relevant [backlog task](docs/embervale/02-roadmap/BACKLOG.md).

Use focused pull requests with exact validation evidence and compatibility notes. The [feature](docs/embervale/08-templates/FEATURE_SPEC.md), [bug](docs/embervale/08-templates/BUG_REPORT.md) and [content review](docs/embervale/08-templates/CONTENT_CHANGE_CHECKLIST.md) templates provide the required context. Keep roadmap and user workflows synchronized with changes.
