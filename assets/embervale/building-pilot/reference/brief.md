# Original architectural reference brief

Generated with OpenAI image generation as a transparent architectural reference.
Final game tiles were authored separately in LibreSprite for the overhead camera.

Use case: stylized-concept. Asset type: original pixel-art workshop reference for
Embervale, a medieval top-down RPG with 32-pixel floor tiles and 36-pixel human
sprites. One isolated rectangular timber-and-stone village workshop, viewed
from above with the south/front wall visible, horizontal front edges and vertical
screen-side walls, never an isometric diamond. Nine tiles wide and five deep.
Weathered warm terracotta shingle roof, a horizontal ridge and visibly layered
tiles; restrained moss at corners. Timber-framed cream plaster front walls over
a low grey-green stone foundation. One open central south doorway with timber
posts/lintel and a stone threshold, no closed door leaf. A blue-grey glass window
on each side. Broad clean pixel clusters, dark outlines, upper-left lighting,
muted olive-grey stone, warm oak timber and brown-red roof (#70412d, #8c5036,
#a75f3c, #ba7748), parchment plaster (#b4a78a, #d0c29e), grey-green stone
(#4b554d, #677165, #858d7a). Native scale roughly 288 pixels wide. No character,
furnace, table, extra props, sign, text, ground rectangle, scenery, glow or cast
shadow outside the building. Actual transparent background. The reference
informs separate exact native wall, doorway, window and roof tiles.
